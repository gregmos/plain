1Plain — a monospace markdown reader/editor for Windows

Assumptions. Windows 11 window chrome (thin title bar, right-aligned controls). No attached design system content, so the direction is set here: IBM Plex Mono throughout, warm paper light theme, soot dark theme, one accent (violet) used only for the caret, selection and the active item. No icons except where a glyph is the label. Three surfaces: Read, Edit (raw markdown), Rich (WYSIWYG-ish). The library lives in a collapsible left rail. Sample document is a short note about plain text.

On plain text

Plain text is the only format that has survived every platform, every editor and every company that tried to own it. A note written in 1985 opens today without ceremony.

Markdown adds just enough structure to stay readable in both directions: as source, and as the thing the source describes. The syntax is the formatting.

The best interface for a paragraph is the paragraph.

Three rules

  1. One file per idea.
  2. Headings are the outline; never nest deeper than two.
  3. Links go to other files, not to the web.
$ ls notes/
ideas.md  on-plain-text.md  reading-list.md

Everything else is decoration.
