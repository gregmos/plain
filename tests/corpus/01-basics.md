# On plain text

Plain text is the only format that has survived every platform, every editor
and every company that tried to own it. A note written in 1985 opens today
without ceremony.

Markdown adds *just enough* structure to stay readable in **both** directions:
as source, and as the thing the source describes.

> The best interface for a paragraph is the paragraph.

## Three rules

1. One file per idea.
2. Headings are the outline; never nest deeper than two.
3. Links go to other files, not to the web.
