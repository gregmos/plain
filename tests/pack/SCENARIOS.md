# Ручные сценарии по тестовому паку

Дополнение к `CHECKLIST.md` (ТЗ §16). Здесь — сценарии на **конкретных файлах пака**, с точным
ожидаемым результатом. Прогоняются на **release**-сборке (`npm run pack`, exe из `dist-win\`).

Перед прогоном:

```powershell
cd "G:\Claude Projects\md reader"
npm run pack:gen          # создаёт tests\pack\generated\ (~14 МБ, в .gitignore)
```

Дальше `$P = "G:\Claude Projects\md reader\tests\pack\generated"` и `$EXE = "…\dist-win\plain.exe"`.

Отметка `✓ дата` — проверено; пусто — ещё нет. Если что-то не сходится — писать **что именно**
(файл, ввод, ожидание, факт), а не «не работает».

## Байтовые проверки — как

```powershell
# до и после
Get-FileHash "$P\library\work\overview.md" -Algorithm SHA256 | Select-Object -ExpandProperty Hash

# BOM и хвост файла
Format-Hex -Path "$P\encodings\utf16le-bom-crlf.md" -Count 8
$len = (Get-Item "$P\encodings\trailing-spaces.md").Length
Format-Hex -Path "$P\encodings\trailing-spaces.md" -Count 16 -Offset ($len - 16)

# побайтовое сравнение с эталоном (эталон — свежая генерация в другую папку)
fc.exe /b "$P\library\work\overview.md" "C:\tmp\pack-ref\library\work\overview.md"
```

Эталон для `fc /b`: скопировать `tests\pack\generated` целиком **до** прогона
(`Copy-Item -Recurse "$P" C:\tmp\pack-ref`) — генератор детерминирован, но копия быстрее и
надёжнее повторной генерации.
