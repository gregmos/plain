# Сохранность

Проверил: окно открывается. Проверил: абзац сохраняется. Таблица читается без лагов — как и обещано в третьем правиле.

## Атомарная запись

| шаг | что делает | почему |
|---|---|---|
| temp | пишет рядом | чтобы не портить оригинал |
| flush | `FlushFileBuffers` | чтобы байты доехали |
| replace | `ReplaceFileW` | сохраняет creation time |

## Кодировки

| кодировка | чтение | запись |
|:--|:-:|--:|
| utf-8 | да | да |
| utf-8 bom | да | да, BOM как был |
| utf-16 | да | да |
| cp1251 | да | после подтверждения в utf-8 |

## Черновики

Поиск сохраняется — даже на файле в мегабайт. Аккуратный черновик читается без лагов, даже на файле в мегабайт. Аккуратный замена сохраняется, если не жать лишнего.

> [!important] Не терять текст
> Черновик удаляется только после подтверждённого сохранения.
