# Plain

Читалка и редактор `.md` для Windows 11. Библиотека — обычная папка: ни базы, ни сети, ни аккаунта.
Три вида одного документа: **read** (рендер), **edit** (исходник) и **rich** (исходник со скрытыми
маркерами). Файл — источник истины: байты, которых ты не трогал, не меняются.

Сделано для себя; версия 0.1.0.

## Установка

1. Распакуй `Plain-0.1.0-win-x64.zip` куда-нибудь к себе — например в
   `%LOCALAPPDATA%\Programs\Plain`. Внутри `plain.exe` и этот README, инсталлятора нет.
2. Первый запуск: exe без подписи, поэтому SmartScreen покажет синее окно
   «Система Windows защитила ваш компьютер». Жми **Подробнее → Выполнить в любом случае**.
   Дальше он больше не спрашивает.
3. По желанию — исключение Defender на папку, чтобы он не проверял каждый запуск и каждое
   сохранение: *Параметры → Конфиденциальность и защита → Безопасность Windows → Защита от вирусов
   и угроз → Управление настройками → Исключения → Добавить исключение → Папка* и указать папку с
   `plain.exe`. Не обязательно, но старт и запись заметно быстрее.

WebView2 в Windows 11 предустановлен, ставить нечего.

Перенёс папку — просто запусти exe с нового места, он перепропишет себя в реестре сам.

## Связать `.md` с Plain

Приложение при каждом запуске регистрируется per-user (`HKCU`) как один из вариантов для `.md` и
`.markdown`, но **не назначает себя по умолчанию** — это твой выбор. Два способа:

- В Проводнике: правый клик на `.md` → *Открыть с помощью* → *Выбрать другое приложение* → Plain →
  *Всегда*.
- Или `help → about` → **default apps**: откроются *Параметры → Приложения по умолчанию*, там Plain
  уже в списке.

Там же, в `about`, есть **unregister** — убрать Plain из «Открыть с помощью». Реестр правится только
в `HKCU\Software\Classes`, `HKCU\Software\Plain` и `HKCU\Software\RegisteredApplications`.

## Где что лежит

Всё в `%APPDATA%\Plain` (это `C:\Users\<ты>\AppData\Roaming\Plain`):

| | |
|---|---|
| `settings.json` | настройки; правятся на экране `Ctrl+,`, внизу там ссылка `open settings.json` |
| `drafts\` | черновики несохранённых правок; при старте предлагается `restore · discard` |
| `state.json` | сессия: открытые файлы, режимы, позиции чтения, окно, последняя папка |

В твоей папке с текстами приложение не создаёт ничего — ни индексов, ни `.plain\`.

## Сборка из исходников

Нужны: Node 22, rustup `stable-x86_64-pc-windows-msvc`, Visual Studio Build Tools с «Desktop
development with C++».

```
npm i
npm run tauri dev     # запуск в режиме разработки
npm run pack          # release-сборка + dist-win\Plain-0.1.0-win-x64.zip
```

`npm run pack` кладёт `plain.exe` и этот README в `dist-win\Plain-0.1.0\` и жмёт папку в zip.
Инсталлятора (NSIS) нет и не планируется.

Проверки: `npm run build` (типы + vite), `npx vitest run`, `cargo test` в `src-tauri`.
Ручной чек-лист перед раздачей — `CHECKLIST.md`.
