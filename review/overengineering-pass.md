# Вычитка ТЗ на оверинжиниринг (2026-09-05)

Контекст: продукт для личного пользования и нескольких знакомых. Критерий: **каждая подсистема должна окупаться за первый месяц использования одним человеком**. Всё, что защищает от сценариев «10 000 пользователей», «враждебный документ», «корпоративная закупка», «сертификация WCAG» — убирается или упрощается до одной строки.

Формат: пункт v1.2 → что не так → решение в v2.0.

## Упрощено (осталось, но короче)

| # | Что | Как |
|---|---|---|
| A | Атомарная запись | temp в той же папке → `ReplaceFileW`; проверка хэша перед записью; на сетевых дисках — `inPlace` по настройке |
| B | Внешние изменения | watcher (`notify`) + polling по настройке; нет правок → перезагрузить, сохранив скролл; есть правки → баннер `reload · keep mine · compare` (diff двумя колонками через jsdiff) |
| C | Rename с обновлением ссылок | только относительные md-ссылки и wikilinks; диалог `update N links? · update · skip`; копии в backup |
| D | Кастомный title bar | пробуем `tauri-plugin-decorum` один день; не работает — системный title bar, breadcrumbs переезжают в полосу режимов |
| E | Word count | `Intl.Segmenter`, без исключения кода — ±5 % никого не волнуют. Нет: исключить fenced code всё же одна строка — исключаем |
| F | Пороги размера | > 2 МБ — large file mode (edit без подсветки, read по кнопке); rich — до 300 КБ |
| G | Quick search | uFuzzy по путям + первые 5 результатов grep + команды. Без `@`/`:`-префиксов (кроме `>`) |
| H | Контекстные меню | одно меню файла (`open · rename · move to… · copy path · reveal in explorer · delete`), одно меню папки (`new file · new folder · rename · reveal · delete`) |
| I | Библиотека-экран | список файлов с сортировкой `modified · name`, фильтр по папке/тегу, `+ new`. Без `created` (NTFS birth time врёт после копирования), без `last read`, без `words`-колонки в сортировке |

## Что осталось «дорогим» осознанно

1. **Кастомный title bar** — потому что это половина визуального впечатления от макетов. Но с честным фолбэком.
2. **Rich как experimental** — потому что это единственная причина не использовать VS Code для заметок. Но без AST-сериализации.
3. **Черновики + атомарная запись + watcher** — потому что потеря текста — единственная непростительная ошибка даже для личного инструмента.
4. **KaTeX + Mermaid в read** — потому что чужие README их содержат, а библиотеки готовые.
