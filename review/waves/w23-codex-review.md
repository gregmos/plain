**Критично**

1. **[sync.ts:60](<G:/Claude Projects/md reader/src/editor/sync.ts:60>) — отложенный текст используется для решения о тихом reload.** До idle-flush `Doc.text` содержит предыдущую версию. Между вводом и flush нажатие F5 либо событие watcher может признать документ чистым: `refresh()` и `checkDoc()` проверяют именно `isDirty(id, doc.text)`. Затем `replaceText()` подменяет актуальный EditorState дисковой версией без подтверждения. Undo может вернуть правку, но пользователь не получает предупреждения, а recovery draft удаляется. **Предложение:** перед решением о reload брать актуальное состояние редактора; после асинхронного чтения повторно проверять revision буфера. Одного flush перед `await` недостаточно.

2. **[pipeline.ts:158](<G:/Claude Projects/md reader/src/read/pipeline.ts:158>) — `source.srcset` обходит запрет автоматической сети.** Проверенный пример `<picture><source srcset="https://example.com/tracker.png"><img></picture>` проходит pipeline без изменений. Откладывается только `img.src`; браузер выбирает изображение из `source.srcset` самостоятельно ([MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/picture)). CSP разрешает HTTPS-картинки. Аналогично проходит `data:image/svg+xml` в `srcset`, минуя SVG guard. **Предложение:** для текущего scope проекта убрать `source`/`srcSet` из schema; поддержка responsive pictures здесь не окупает дополнительный путь проверки.

**Стоит поправить**

3. **[commands.ts:122](<G:/Claude Projects/md reader/src/editor/commands.ts:122>) — code block не работает как toggle.** Проверено: выделить `abc`, вызвать команду дважды — получится пять строк fences/content вместо исходного текста. После первого вызова выделение остаётся внутри fences, а снятие требует выделить сами fences. При нескольких раздельных selections команда также оборачивает весь промежуток между первым и последним, включая невыделенный текст. **Предложение:** распознавать окружающую пару fences и обрабатывать отдельные непрерывные группы выбранных строк.

4. **[commands.ts:42](<G:/Claude Projects/md reader/src/editor/commands.ts:42>) — italic внутри bold нельзя снять повторным вызовом.** Проверено на выделенном `abc` в `**abc**`: первый `Ctrl+I` даёт `***abc***`, второй — `****abc****`. `partOfBold()` блокирует снятие и у тройной последовательности. **Предложение:** различать двойные и тройные delimiters; добавить round-trip для bold + italic.

5. **[commands.ts:27](<G:/Claude Projects/md reader/src/editor/commands.ts:27>) — затрагивается строка за границей выделения.** Выделение `[0, 4)` в `one\ntwo` возвращает обе строки, хотя из второй не выбран ни один символ. Heading, quote, list и checkbox меняют лишнюю строку. **Предложение:** для непустого range, заканчивающегося в начале строки, считать последней затронутой строкой `lineAt(range.to - 1)`.

6. **[commands.ts:51](<G:/Claude Projects/md reader/src/editor/commands.ts:51>) — собственные команды обходят read-only.** Они не проверяют `state.readOnly`; сам `state.update()` изменения не запрещает. Проверено: `toggleBold` меняет документ с `EditorState.readOnly.of(true)`, хотя обычный ввод заблокирован. То же относится к другим собственным formatting-командам и toolbar. **Предложение:** единый guard для изменяющих команд, применяемый также при вызове через меню.

7. **[ReadView.tsx:245](<G:/Claude Projects/md reader/src/read/ReadView.tsx:245>) — возврат в edit уничтожает сохранённое выделение.** Cleanup всегда отправляет goto-line, а `jump()` заменяет selection единственной кареткой в начале заголовка. Сценарий: выделить текст → read → edit — выделение потеряно, несмотря на сохранённый EditorState. Это расходится с §5.0: требуется сохранить selection и отдельно поставить scroll на заголовок. **Предложение:** разделить «прокрутить к строке» и «перенести каретку».

8. **[Outline.tsx:27](<G:/Claude Projects/md reader/src/ui/Outline.tsx:27>) — outline в edit использует устаревшие строки.** `doc.headings` обновляется только ReadView. После вставки строк над заголовком кнопка ведёт на старый номер; документ, открытый сразу в edit, вообще остаётся без outline. **Предложение:** обновлять позиции заголовков из актуального буфера с debounce либо вычислять актуальную цель при клике. Полный HTML-render на вводе не нужен.

9. **[headings.ts:18](<G:/Claude Projects/md reader/src/editor/headings.ts:18>) — edit и read вычисляют разные heading IDs.** Проверено: `# [[file|Alias]]` получает `alias` в read и `file` в edit; setext-заголовок отсутствует в editor-списке вообще. Поэтому переход edit → read не находит цель. Boolean-переключение fences также не учитывает их тип и длину. **Предложение:** использовать общий источник heading metadata на переходе между режимами; второй упрощённый Markdown parser уже требует больше поддержки, чем экономит.

10. **[ReadView.tsx:183](<G:/Claude Projects/md reader/src/read/ReadView.tsx:183>) — одинаковый HTML разных документов сохраняет чужие картинки.** При переключении между двумя файлами с одинаковым `![](image.png)` HTML не меняется, поэтому DOM не пересоздаётся. Предыдущий `enhance()` уже удалил `data-src` и записал абсолютный путь; повторный проход с новым `dir` такую картинку пропускает. Она продолжает показывать файл из предыдущей папки. **Предложение:** пересоздавать исходный DOM также при смене document identity/base directory.

11. **[FindBar.tsx:28](<G:/Claude Projects/md reader/src/read/FindBar.tsx:28>) — поиск пересчитывается раньше замены DOM.** При открытом find и смене документа `useMemo` ищет в старом содержимом; новое `innerHTML` устанавливается позже, в effect родителя. Полученные Range после этого относятся к удалённым узлам. Дополнительно `nonce + html.length` не различает разные документы одинаковой длины. **Предложение:** пересчитывать поиск после установки и обработки DOM, передавая настоящую revision вместо длины HTML.

12. **[findPanel.ts:123](<G:/Claude Projects/md reader/src/editor/findPanel.ts:123>) — F3 в поле поиска выполняется дважды.** Локальный handler вызывает `findNext`, затем событие доходит до глобального tinykeys, который отправляет `FIND_STEP`; remote listener вызывает `findNext` снова. `preventDefault()` не останавливает propagation, а установленный tinykeys не пропускает такие события. **Предложение:** оставить F3 одному владельцу — глобальному registry — и убрать локальное дублирование.

13. **[setup.ts:177](<G:/Claude Projects/md reader/src/editor/setup.ts:177>) — отсутствует вставка URL поверх выделения.** Paste handler для `[выделение](url)` нигде в editor не подключён. Обычная вставка заменяет выбранный текст адресом, вопреки §5.2. **Предложение:** небольшой paste handler для URL и непустого selection, с отдельным обходом для plain paste и IME.

14. **[ReadView.tsx:94](<G:/Claude Projects/md reader/src/read/ReadView.tsx:94>) — синхронный render способен надолго заблокировать интерфейс.** На синтетических ASCII-файлах около 1 МБ получил примерно 29,7 секунды для повторяющихся Markdown-параграфов и 31,3 секунды для множества коротких code blocks. Это Node 22, не измерение WebView2, но весь этот вызов находится внутри React render. Кроме того, idle-flush запускает полный word count на том же UI thread: перенос за пределы CM update не делает работу неблокирующей. **Предложение:** проверить эти случаи в WebView2; тяжёлый render/count вынести в Worker с revision документа. Оптимизация ограниченного viewport-прохода `lineLook` здесь вторична.

15. **[words.ts:29](<G:/Claude Projects/md reader/src/read/words.ts:29>) — fenced code внутри blockquote считается словами.** Проверено: `> ```\n> many code words\n> ```` даёт три слова, хотя read строит code block. Regex видит только fences верхнего уровня; аналогичная проблема возникает во вложенных списках. **Предложение:** в read считать слова по уже разобранному Markdown tree, исключая code nodes; не расширять отдельный regex-парсер последовательностью исключений.

**Вкусовщина**

16. **[ReadView.tsx:28](<G:/Claude Projects/md reader/src/read/ReadView.tsx:28>) — `scrollTops` не очищается при закрытии документов.** За сессию остаются записи всех прочитанных файлов, включая переименованные пути. Для одного пользователя объём небольшой, отдельный LRU здесь избыточен. **Предложение:** удалять запись при закрытии документа; долговременная позиция уже хранится отдельно.
