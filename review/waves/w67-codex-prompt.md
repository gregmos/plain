Ты ревьюишь финальное состояние v0.1 проекта Plain — личного Markdown reader/editor для Windows (Tauri 2 + React 19 + TS + Vite + CodeMirror 6 + Rust). Ничего не правь — только читай и пиши отзыв.

Контекст: личный проект для одного человека; норма — `ТЗ-Plain.md` v2.3 (§1.3, §4 «Меню», §5.2 «Плавающая панель», §5.3 Rich, §8, §10, §13, §14, §16). Предыдущие твои ревью (`review/waves/w1-codex-review.md`, `w23-…`, `w45-…`) применены; тест-пак `tests/pack/` (см. `SCENARIOS.md`), release-сборка прогнана вручную. Тесты: 423 vitest, 46+9 cargo — зелёные.

Что ревьюить (новое с прошлого раза):
1. **Волна 6 — Windows**: `src-tauri/src/assoc.rs` (ассоциация `.md` в HKCU, `register_quietly` в setup только в release), `scripts/pack.ps1`, `src-tauri/tauri.conf.json` (bundle off), `README.md` (английский, для раздачи людям — проверь фактическую точность против кода: SmartScreen, `Open with`, где данные, что сохраняется), `CHECKLIST.md`.
2. **Волна 7 — rich**: `src/editor/rich.ts` (Decoration.replace по syntaxTree + regex для `==`/`[[ ]]`, виджет чекбокса, активные строки без скрытия), `src/editor/EditView.tsx` (реконфигурация compartment, `useLayoutEffect`-снятие позиции, `takePending` с возвратом при неизмеренной вьюхе), `src/editor/headings.ts`.
3. **Меню и экраны**: `src/ui/MenuBar.tsx` (Radix Menubar), `src/app/menu.ts` (модель), `src/ui/Settings.tsx`, `src/ui/Shortcuts.tsx`, `src/app/registry.ts` (единый реестр команд: дубли/конфликты chord'ов между реестром, CM6 keymap, `remote.ts` и SWALLOW в `keys.ts`), `src/editor/toolbar.ts`.
4. **Экспорт**: `src/app/commands.ts` (`plainTextOf`/`htmlToPlainText` — самодельный HTML→text сканер: корректность на вложенных тегах, entity, `<pre>`; `exportText`, печать `Ctrl+P` через `window.print` и `@media print` в `app.css`/`read.css`).
5. **Правки после ревью**: `src/read/pipeline.ts` + `markdown.ts` + `headings.ts` (один парс на документ, кэш по тексту, один slugger для markdown- и HTML-заголовков), `src/read/links.ts` (wikilinks по имени библиотеки, `libraryFiles()` из `src/library/tree.ts`), `src/read/outline.ts` `restoreTarget`, `src/library/fuzzy.ts` (uFuzzy unicode), `src/app/save.ts`/`close.ts`/`drafts.ts`/`watcher.ts` (live-проверки dirty через `flushActiveEditor`, `Doc.revision`, очередь черновиков), `src-tauri/src/fs.rs` (`canonical`, `recover_replacement`, `stage`/`commit`, decode/encode errors, отказанная запись не создаёт папку), `tree.rs` (`create_file` no-clobber), `search.rs` (декодер, окно вокруг совпадения).

Ищем, по приоритету: (1) потеря/порча текста и гонки в §8-путях; (2) баги в новых экранах/меню/rich (утечки слушателей, декорации на границах, чекбокс-виджет и undo); (3) реестр/хоткеи — что вызывается дважды или не вызывается; (4) README — неточности; (5) оверинжиниринг по критерию «окупится ли за месяц использования одним человеком». Формат: список находок файл:строка, суть, почему важно, предложение; «критично / стоит поправить / вкусовщина». Без пересказа и похвал. По-русски, термины по-английски.
