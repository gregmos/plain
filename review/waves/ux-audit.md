# UX-аудит Plain v0.2 (2026-09-06, Opus-агент, только отчёт)

Стенд: git worktree на `e214097`, vite в Chrome; вне Tauri нет файловых диалогов, watcher и чтения с диска.

## Мешает каждый день
1. Read и все экраны не листаются с клавиатуры: скроллится `.content.read`/`.screen` с `tabIndex=-1`, фокус туда не попадает; работают только колесо и полоса.
2. Позиция чтения теряется после любого экрана (read 250px → `Ctrl+,` → `Esc` → 0); в edit сохраняется.
3. `Enter` в диалогах подтверждения запускает разрушительное действие: `Modal` фокусирует первую кнопку (`move to recycle bin`, `reload`, `reopen`, `reset`, `save anyway`, `restore`, `delete`).
4. Из модала уходит фокус наружу, focus trap нет.

## Раздражает
5. `Ctrl+H` в read переключает в edit, но панель replace не открывается (EditView монтируется позже события).
6. `Ctrl+H` ставит каретку в `replace`, а не в пустой `find`.
7. Хоткеи в палитре печатаются задом наперёд (`, ctrl`, `\ ctrl shift`): `.qs-where` с `direction: rtl`.
8. Полоса режимов «живая» без документа; клик по режиму при открытом экране и без документа не закрывает экран.
9. Открытый файл в рейке закрывается только средней кнопкой, нет `×` на hover и `title` с полным именем.
10. `Ctrl+S` не даёт обратной связи, кроме слова `saved` в правом углу; `save` на чистом документе молчит.
11. Второй баннер теряется молча (один слот); у `drafts`/`save-failed` нет `dismiss` и причины.
12. Экран восстановления нельзя отложить; `discard`/`discard all` без подтверждения.
13. 480×400: рейка 232px съедает половину, колонка ~180px, breadcrumbs схлопываются в один `/`.
14. Settings при узком окне: имена ключей налезают на значения.
15. Library при узком окне: колонка имени 0px, горизонтальный скролл.
16. Поиск по папке: нет `↑↓`/`Enter`, клик всегда открывает в edit.
17. Disabled-пункты меню на `--faint` ≈ 1.55:1, не читаются.
18. Подменю `heading ▸` в `edit` не выключается в read, хотя все дети disabled.
19. Compare: нет перехода по различиям, подписи `disk · buffer` не соотнесены со строками.

## Косметика
20. `about` показывает `plain 0.1.0` (жёстко в коде).
21. Подпись `appearance.theme`: `dark follows windows…` вместо `system follows windows…`.
22. `ctrl alt l` и `ctrl alt 1` неразличимы на 10.5px.
23. Статус-бар не выглядит кликабельным (нет `title` у темы, `cursor: default`).
24. `saved` у нового безымянного буфера.
25. Пустой редактор после `Ctrl+N` без placeholder (в макете 1d есть).
26. Focus mode нечем выключить мышью.
27. Сортировка library без разделителей `·`.
28. Якоря `#` попадают в Tab-обход и невидимы в фокусе.
29. `Plain` в заголовке окна против `plain` в микрокопии.

## Сделано хорошо
Однородная микрокопия; тёмная тема доведена до конца (muted 4.9:1/4.86:1); quick search; read-only снимки на уровне CodeMirror; edit переживает переходы (скролл и фокус возвращаются).
