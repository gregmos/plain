## Ориентиры (ТЗ §1.3)

Не обязательства, а то, что должно оставаться правдой. Замеры 2026-09-05, release-сборка,
Windows 11 x64, файл `note.md` (179 байт).

| | Замер | Отметка |
|---|---|---|
| Холодный старт до окна | 1002 мс на самом первом запуске нового exe (Defender + первое чтение с диска), дальше 109–137 мс до окна и ~1.5 с до текста на экране | ✓ 2026-09-05 |
| Память с открытым файлом | `plain.exe` + его процессы WebView2: 383 МБ working set, 182 МБ private bytes; с файлом 10 МБ — 422 МБ working set | ✓ 2026-09-05 |
| Размер `plain.exe` | 15.2 МБ, в zip 7.0 МБ | ✓ 2026-09-05 |

Про память: WebView2 — это Chromium, и его working set меряется вместе с общими страницами runtime,
поэтому число выглядит большим. Ориентир ТЗ («меньше VS Code») держится, но не с запасом; честнее
смотреть на private bytes.
